# 🏠 Início

Este é o caderno do projeto. Ele mora no PC e aparece no celular pelo Syncthing.

| Pasta | De quem é | Para que serve |
|---|---|---|
| **01 💡 Ideias** | sua | Ideias rápidas. O sistema não muda suas notas. |
| **02 📝 Minhas notas** | sua | Seus planos, reflexões e anotações. |
| **03 🗺️ Entender o projeto** | escrita pelo Claude | Explicação humana do projeto. Pode ser reescrita quando o projeto muda; comentários vão em 💡 Ideias. |
| **04 🧭 Decisões** | atualizada sozinha | O que você decidiu no Grimório. |
| **05 📅 Diário do sistema** | atualizada sozinha | O que publicou, falhou e foi registrado. |
| **99 🧩 Modelos** | moldes | Formatos prontos para suas notas. |

> [!important] Uma regra só
> **01 e 02 são suas — o sistema nunca escreve nelas.** Para comentar uma nota automática, escreva em 💡 Ideias e ponha o link.

## Como usar

- **Ideia rápida:** nota nova → ⋯ → Inserir modelo → **Ideia**.
- **Pedir algo para a equipe:** no app, use **⏳ Agora → 📝 Pedir**. Para continuar um pedido já aberto, aperte **Responder**.
- **Algo estranho:** nota nova → ⋯ → Inserir modelo → **Problema**.
- **Planejar:** nota nova → ⋯ → Inserir modelo → **Plano**.
